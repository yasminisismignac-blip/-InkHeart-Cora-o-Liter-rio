# 🫀 InkHeart — Coração Literário (Cirúrgico)

Parceira do **[TokenSaver](https://github.com/yasminisismignac-blip/TokenSaver---ST)**.

O TokenSaver deixa o prompt leve; o InkHeart usa uma fatia pequena desse espaço para **melhorar a escrita sem encher linguiça**.

## O que mudou na versão 2.0

- **Perfil padrão `natural`**: regras de ouro, não manuais. Foco em subtexto, ação concreta e diálogos com intenção.
- **No máximo 3 diretivas por turno** no bloco final (1 foco, 1 gancho, 1 final).
- **Sem checklist silencioso**, **sem ritmo complexo forçado**, **sem meta de palavras** por padrão.
- **Âncora de uma frase**: essência do personagem, sem amolecer.
- **Radar adaptativo cirúrgico**: só avisa se houver repetição real, de forma direta.
- **Sampler desligado por padrão** (sem `presence_penalty`/`frequency_penalty` forçados).

## Instalação

1. Crie um repositório público no GitHub.
2. Suba os arquivos com os nomes exatos: `manifest.json`, `index.js`, `style.css`, `README.md` e a pasta `src/`.
3. No SillyTavern: **Extensions → Install extension** → cole a URL do repositório.
4. Recarregue a página e procure **🫀 InkHeart** em *Extensions*.

## Configuração rápida

1. Mantenha **Intensidade: Sutil**.
2. Escolha o perfil **Natural** (ou Literário Contido se quiser algo mais descritivo, mas ainda contido).
3. Deixe **Meta de palavras** em `0`.
4. Ative **Radar adaptativo** apenas se notar repetição excessiva.
5. Clique em **👁️ Ver última injeção** para conferir exatamente o que foi enviado.

## Filosofia

Menos instruções, mais autoridade. O modelo recebe diretivas claras e comportamentais, não uma lista de adjetivos para cumprir.
